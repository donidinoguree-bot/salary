Нягтлан бодогчийн самбар

Excel файл оруулж, шинэ сарын цалингийн мэдээллийг Gist рүү шинэчилнэ

1. Gist тохиргоо

Token-д тухайн Gist-ийг унших/бичих эрх ("gist" scope) хэрэгтэй. Token хаана ч хадгалагдахгүй, зөвхөн энэ хуудсыг сэргээх/хаах хүртэл санах ойд байна.

2. Excel оруулах (нэг сар эсвэл олон сар)

Хэрэв танд олон сарын мэдээлэл нэг дор байгаа бол: Excel файлдаа сар бүрийг тусдаа sheet (доод табууд) болгож, sheet бүрийн нэрийг сарын нэрээр (жиш: "7-р сар", "8-р сар", "9-р сар") нэрлээд upload хийнэ үү. Апп бүх sheet-ийг тус тусад нь тухайн сарын мэдээлэл гэж таньж, нэг дор Gist рүү шинэчилнэ. Ганц sheet-тэй файлд дээрх "Сарын нэр" талбар хэрэглэгдэнэ.

3. Ажилтан удирдах

Энд ажилтан нэмэх, хасах (идэвхгүй болгох), нууц үг тохируулах боломжтой. Өөрчлөлт хийхийн тулд дээрх "1. Gist тохиргоо" хэсэгт Gist ID болон GitHub Token-ыг оруулсан байх шаардлагатай.

4. Уншсан мэдээллийг шалгах

5. Сарын өгөгдөл засах (ажилласан хугацааны цалин ↔ илүү цагийн цалин)

Тухайн сарын "Ажилласан хугацааны цалин" 0 болж, тэр дүн нь "Илүү цагийн цалин" руу орчихсон бол энд засна. Зөвхөн ажилласан хугацааны цалин = 0, илүү цагийн цалин > 0, илүү цагийн цаг = 0 байгаа мөрийг л автоматаар зөөнө; илүү цаг нь бодитоор байгаа мөрийг гар хүрэлгүй жагсаалтад тусад нь харуулна.
